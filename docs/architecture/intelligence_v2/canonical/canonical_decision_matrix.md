# Intelligence V2 Canonical Decision Matrix

## Intelligence Artifact

Canonical criteria:

- immutable identity
- confidence validation
- provenance support
- metadata support
- serialization compatibility


## Registry

Canonical criteria:

- engine registration
- adapter registration
- contract registration
- runtime discovery


## Kernel

Canonical criteria:

- lifecycle ownership
- subsystem initialization
- component coordination


## Runtime

Canonical criteria:

- execution context
- memory interaction
- telemetry emission
- artifact creation


## Bootstrap

Canonical criteria:

- single initialization path
- deterministic defaults
- test reproducibility


## Contracts

Canonical criteria:

- stable interfaces
- no duplicate schemas
- backward compatibility where required
